# Raretés, notes et époques (règles v4/v5, validées par Harlem)

## Rareté = rang de la VERSION dans son monde
UR = sommet reconnu de l'œuvre · SSR = élite (boss d'arcs majeurs) · SR = élite secondaire (capitaines, généraux, Piliers) · R = combattants solides · N = faibles, débutants, civils.

## Bandes de note fixes, sans chevauchement
N 40–54 · R 55–64 · SR 65–74 · SSR 75–89 · UR 90–96 · LR 97–99. Une rareté plus haute est TOUJOURS plus forte.
Dans une bande : ordre strict de puissance dans le monde (égalité permise entre persos de force égale). Les versions d'un même perso suivent leur ordre.

## Plafond du monde (classe de puissance)
- A cosmique (Dragon Ball, One Punch Man) : SSR ≤ 89, UR ≤ 96
- B très haut (One Piece, Naruto, Bleach, JJK, HxH, Hellsing, JoJo, Chainsaw Man, Solo Leveling, FMA, AoT, Saint Seiya) : SSR ≤ 89, UR ≤ 95
- C haut (MHA, Demon Slayer, Trigun, Frieren) : SSR ≤ 85, UR ≤ 92
- D (Black Clover, Fairy Tail…) : SSR ≤ 84
- E humain (Kingdom, Black Lagoon) : SSR ≤ 80, UR ≤ 90

## Quotas par monde
UR ≤ 2 (la 2e seulement à égalité canonique) ; SSR+UR ≤ 22 % du monde (minimum 3) ; monde sans UR : 1 SSR de plus. Global visé : SSR 12–15 %, UR ≤ 6 %.
Soutiens : placés par la valeur de leur effet ; +1 cran seulement pour LE soutien clé de leur monde.

## Ajouts futurs
Une nouvelle carte se place **entre ses voisines**, sans toucher aux existantes. Plus forte que les 2 UR du monde → LR (jamais une 3e UR). Une transformation = une carte à part, au rang de cette forme. UR plafonnées à 96 ; LR 97–99.

## Nouveau monde
Classe A–E avec 2-3 repères croisés ; 12 cartes minimum (1 UR, 2 SSR, 3 SR, 3 R, 3-4 N) ; au moins 1 Tank et 1 Soutien ; pas que des stars.
À créer dans `index.html` : `MONDES` (nom + kanji), `MSH` (abréviation), `CREW` (gardiens de Tour), couleur `--m-xx`. Vérifier que la Tour tire ses mondes sur le nombre réel de mondes (`twFloor`).

## Règles d'époque
1. On note ce qui est MONTRÉ à cette époque (combats, exploits) + ce que l'œuvre affirme comme un fait À CE MOMENT. Pas la réputation future. Peu d'exploits → préférer une époque où le perso agit.
2. Une carte = un moment réel (arc où il combat, moment culte), jamais un intitulé flou (« Légendaire », « Pilier de… », « Professeur »).
3. Un seul exemplaire d'un perso → son moment phare, en général le plus fort montré. Perso toujours fort (Kakashi, Shanks, Guy, Gojo) → jamais une petite époque.
4. Petite époque seulement si culte en elle-même (Luffy East Blue, Naruto Académie, Goku Enfant, Sung Jinwoo Rang E, Deku Entrée) ET si le perso a aussi sa grande époque. Jamais « pour vendre la grande plus tard ».
5. Plusieurs cartes d'un perso : époques différentes, écart de puissance réel, jamais deux cartes du même arc au même niveau.
6. Nom de version : **« Forme · Époque »**. « contre X » est RÉSERVÉ aux scènes iconiques (ex. Gear 5 contre Kaido).
